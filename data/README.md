# Data — synthetic educational only

> **This folder contains synthetic data created for an educational finance/audit
> exercise. It contains no real employer, client, bank, payroll or personal
> financial data. It is not an audit opinion, assurance engagement or financial
> advice.**

## Primary dataset

| File | Purpose |
|---|---|
| `synthetic_retail_expenses.csv` | H1 2026 expense ledger, 454 rows, 8 columns |
| `synthetic_retail_expenses.metadata.json` | Generation metadata, totals and full anomaly register |

Every row carries `data_source = SYNTHETIC_EDUCATIONAL` so the file cannot be
mistaken for real financial records.

### Schema

| Column | Type | Notes |
|---|---|---|
| `txn_id` | text | `TXN-2001` … unique identifier added for traceability |
| `date` | text | ISO `YYYY-MM-DD`; deliberately includes blanks and malformed values |
| `department` | text | 5 departments |
| `category` | text | 8 canonical categories plus planted variants |
| `description` | text | Free text, vendor included |
| `budget` | decimal | Monthly budget for the line, EUR, VAT-exclusive |
| `actual_amount` | decimal | Actual spend, EUR, VAT-exclusive; may be negative for credits |
| `data_source` | text | Always `SYNTHETIC_EDUCATIONAL` |

### How it is generated

```bash
python scripts/generate_synthetic_data.py --rows 450 --seed 20261122
```

The generator is seeded and deterministic. `--rows` controls the number of clean
base rows; planted anomalies are added on top.

### Planted anomalies

| Type | Rows | Purpose |
|---|---|---|
| `exact_duplicate` | 2 | Duplicate payment / double posting test |
| `near_duplicate` | 2 | Same amount and description, date shifted |
| `missing_date` | 4 | Blank date handling |
| `malformed_date` | 4 | Invalid and non-ISO date formats |
| `inconsistent_category` | 6 | Casing, whitespace, typo and synonym variants |
| `negative_actual` | 4 | Credit notes / refunds (legitimate) |
| `negative_budget` | 1 | Entry error |
| `extreme_outlier` | 3 | One-off operational spikes |
| `zero_budget` | 3 | Unbudgeted spend |
| `tiny_budget` | 2 | Denominator not meaningful |
| `out_of_period_date` | 2 | 2025-12-28 and 2026-07-03 |
| `blank_description` | 2 | Missing narrative |

## Generated outputs

`processed/` is written by `scripts/etl_review.py` from the canonical dataset above.
It is fully regenerable and should not be edited by hand:

| File | Content |
|---|---|
| `expenses_audited_all.csv` | All 454 rows with flags, disposition and variance |
| `expenses_clean.csv` | 442 included rows used for analysis |
| `dq_exceptions_log.csv` | Every flagged, corrected or quarantined row |
| `dq_summary.csv` | 17 data-quality checks with rows and amounts |
| `reconciliation.csv` | Raw-to-clean bridge (check row must be 0.00) |
| `category_mapping_log.csv` | Every label correction with before/after |
| `summary_by_*.csv` | Category, month, month×category and department summaries |
| `top_*_items.csv`, `follow_up_candidates.csv` | Line-item extracts |
